# Fanov Parking Services Bot

Telegram-бот для автоматизации бронирования парковочных мест, управления балансом и валидации въезда по динамическим QR-кодам. Проект разработан как сервисный компонент инфраструктуры Fanov Parking Services (FPS).

## Возможности

- **Интерактивный выбор парковки** — навигация по городам, отображение доступных адресов и отправка точных геолокационных меток.
- **Мониторинг свободных мест** — учет общего и текущего доступного количества парковочных слотов в реальном времени.
- **Бронирование с валидацией госномера** — встроенный парсер формата автомобильных номеров и привязка брони к пользователю.
- **Генерация QR-пропусков** — создание индивидуального QR-кода со спойлером для авторизации на автоматическом шлагбауме/терминале въезда.
- **Управление балансом и профилем** — фиксация даты регистрации, списание средств за бронирование и просмотр личного кабинета.

## Стек технологий

| Компонент | Технология |
|---|---|
| Язык | Python 3.10+ |
| Telegram API | aiogram 2.25 (FSM) |
| База данных | SQLite 3 |
| Графика / Пропуска | Pillow, qrcode |

## Структура проекта

```
Fanov_Parking_Services.bot/
├── main.py          # Основная логика: хендлеры, FSM бронирования, генерация QR
├── config.py        # Конфигурация: токен бота, служебные параметры
├── db.py            # Слой работы с БД SQLite (CRUD пользователей и парковок)
├── keyboard.py      # Меню, инлайн-клавиатуры городов и парковок
├── park_db.db       # База данных SQLite
└── requirements.txt # Зависимости
```

## Установка и запуск

1. Клонирование репозитория:
```bash
git clone https://github.com/ijstt/Fanov_Parking_Services.bot.git
cd Fanov_Parking_Services.bot
```

2. Установка зависимостей:
```bash
pip install -r requirements.txt
```

3. Настройка конфигурации:
Создайте или отредактируйте `config.py`, указав токен Telegram-бота:
```python
TOKEN = "YOUR_BOT_TOKEN"
```

4. Запуск бота:
```bash
python main.py
```

## Примечание по тестированию

Для локального тестирования сценариев бронирования требуется наличие положительного баланса в таблице `users` базы данных `park_db.db` (поле `balance > 150`).
